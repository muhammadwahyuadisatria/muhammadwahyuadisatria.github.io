Featured Work

Main Project

Capstone Design · Mobile Application

MoNas — Monitoring Nutritional Status of Children

An end-to-end Android application that estimates toddlers' height and weight from smartphone photos and classifies nutritional status against WHO and Indonesian Ministry of Health anthropometric standards.

Key Contributions

  • Built the Flutter front end with offline-first local storage in SQLite, including an examination history log with PDF export.
  • Developed a RESTful backend with FastAPI and deployed it to the cloud (Railway) with GitHub-integrated CI/CD for automatic deployment on every code change.
  • Implemented an HSV-based digital image processing pipeline in OpenCV (background segmentation, thresholding, body masking) and benchmarked it against a Canny edge-detection baseline, showing HSV delivered higher measurement accuracy.
  • Implemented nutritional status classification based on WHO and Indonesian Ministry of Health anthropometric standards.
  • Validated the system on 26 real toddler cases collected from Posyandu and TK Al Munar.
